# 0613. Desenvolupament web en entorn servidor

> Hub curricular de treball. La formulació de RA i CA es conserva al [[../../raw/sources/2526_Servidor-master/00_general/RA|document de partida]] i als fulls `UT1`–`UT4` de la [[../../raw/sources/IFC33C - Desenvolupament web en entorn servidor.xlsx|programació 2026–2027]]. El codi **0613** consta al [RD 405/2023](https://www.boe.es/eli/es/rd/2023/05/29/405).

## Finalitat

Desenvolupar aplicacions web de servidor amb generació dinàmica, persistència, serveis web i integració amb el client, mantenint la separació entre domini, accés a dades, lògica de negoci i presentació. L'[[orientacio-docent|orientació docent]] del ZIP fixa el fil conductor personal: casos d'ús, consultes precises, serveis amb lògica de negoci, controladors lleugers, DTOs, proves, logging i seguretat transversal.

La [[fonts/programacio-didactica-2026-2027|programació 2026–2027]] fixa **230 hores** totals, **7 setmanals** i quatre unitats de **20, 40, 50 i 120 hores**. Les [[matrius/qualificacio-ra-2026-2027|ponderacions dels RA]] sumen el 100%.
