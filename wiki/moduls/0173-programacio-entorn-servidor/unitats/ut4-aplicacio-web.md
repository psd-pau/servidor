# U4. Desenvolupament d'aplicacions web

## RA i criteris d'avaluació

- RA2 — pàgines dinàmiques amb codi embegut (`RA2.a`–`RA2.h`).
- RA3 — estructures de control i formularis (`RA3.a`–`RA3.g`).
- RA4 — estat, autenticació, proves i depuració (`RA4.a`–`RA4.f`).
- RA5 — separació de lògica de negoci i presentació (`RA5.a`–`RA5.h`).
- RA8 — integració de tecnologies de client i servidor (`RA8.a`–`RA8.g`).

## Finalitat i evidència

Integrar una aplicació web completa amb formularis, validació, estat, autenticació i interacció client-servidor. Evidència orientativa: repositori executable, demostració guiada, proves i documentació d'arquitectura.

## Continguts i tecnologia

Generació dinàmica, estructures de control, manteniment d'estat, seguretat, MVC, patrons, JavaScript al client i plantilles Thymeleaf al servidor. Els DTOs, mappers, `@ControllerAdvice` i SLF4J són pràctiques professionals de suport quan ajudin a fer visible la separació de responsabilitats.
