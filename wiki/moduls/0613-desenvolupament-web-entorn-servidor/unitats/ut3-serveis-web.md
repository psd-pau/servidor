# U3. Serveis web

**Durada programada:** 50 hores, octubre–desembre. **Pes:** RA7 20% i RA9 5% del mòdul; el llibre marca un 10% en empresa de cadascun d'aquests RA. Font: [[../../../fonts/programacio-didactica-2026-2027|programació 2026–2027]], fulls `UT3`, `6-Distribució temporal` i `2-ANCORATGE CURRICULAR`.

## RA i criteris d'avaluació

- RA7 — desenvolupament i consum de serveis web (`RA7.a`–`RA7.h`).
- RA9 — reutilització de components i fonts d'informació existents (`RA9.a`–`RA9.h`).

## Finalitat i evidència

Dissenyar, implementar, provar, documentar i consumir un servei web, incorporant una font o component extern de manera justificada. Evidència orientativa: API amb contracte documentat, col·lecció de proves i client consumidor.

## Continguts i tecnologia

Protocols, formats d'intercanvi, arquitectures i eines de prova/documentació. Amb Spring, la pràctica pot concretar-se en una API REST; aquesta és una decisió tecnològica, no la formulació del RA.

## Materials, avaluació i millores

- Registre d'aula: les activitats i els instruments s'hi anotaran quan es facin. L'API i el client consumidor són exemples orientatius de la wiki.
- Cal separar evidències de creació/consum del servei (`RA7`) de les de reutilització, repositoris o processament d'informació (`RA9`), inclosa la part d'empresa.
