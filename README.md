# Programació en entorn servidor

Base de coneixement per preparar el mòdul `0613. Desenvolupament web en entorn servidor` del cicle de Desenvolupament d'Aplicacions Web (DAW).

La documentació inicial i la programació didàctica 2026–2027 es conserven a `raw/sources/`. La capa de treball és la [[wiki/index|wiki]], on hi ha el context del curs, les síntesis de les fonts, el mapa de RA i les fitxes de les unitats.

## Estructura

- `raw/`: fonts originals; no s'editen.
- `wiki/`: coneixement viu, síntesis, decisions i traçabilitat curricular.
- `materials/`: materials vigents per a l'alumnat.
- `materials-anteriors/`: materials reutilitzables o històrics.

Consulteu `AGENTS.md` per a les convencions de manteniment.
