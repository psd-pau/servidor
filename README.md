# Programació en entorn servidor

Base de coneixement per preparar el mòdul `0173. Programació en entorn servidor` del cicle de Desenvolupament d'Aplicacions Web (DAW).

La documentació inicial rebuda es conserva immutable a `raw/sources/2526_Servidor-master/`. La capa de treball és la [[wiki/index|wiki]], on hi ha el context del curs, la síntesi de la font, el mapa de RA i les fitxes de les unitats.

## Estructura

- `raw/`: fonts originals; no s'editen.
- `wiki/`: coneixement viu, síntesis, decisions i traçabilitat curricular.
- `materials/`: materials vigents per a l'alumnat.
- `materials-anteriors/`: materials reutilitzables o històrics.

Consulteu `AGENTS.md` per a les convencions de manteniment.
