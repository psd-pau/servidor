# Materials de la UT2 — Curs 2026–2027

La font de teoria en elaboració és [acces-a-dades-amb-spring.md](acces-a-dades-amb-spring.md). És un **esborrany inicial**, no uns apunts revisats ni un registre del que ja s'ha impartit. El dossier DOCX i el PDF encara no s'han generat.

L'esborrany es va iniciar amb el [code along `unitat_2_classe2526`](../../../wiki/fonts/code-along-ut2-2526.md). El 2026-10-09 el professor confirma que [unitat_2_ordinador_profe](../../../wiki/fonts/code-along-ut2-ordinador-profe.md) és posterior i el designa com a **font històrica canònica**; totes dues fonts es conserven a `materials-anteriors/`. La [fitxa de la UT2](../../../wiki/moduls/0613-desenvolupament-web-entorn-servidor/unitats/ut2-acces-dades.md) conté la traçabilitat amb `RA6` i els criteris d'avaluació.

**Projecte actual proposat:** [unitat2_2627/README.md](unitat2_2627/README.md) documenta la fusió de les dues versions per al code along 2026–2027, amb compilació i 14 proves superades. Inclou els tres fitxers HTTP originals: el senzill `test-api.http` com a primer exemple, i `book_read.http` i `book_write.http` com a ampliacions; també hi ha exemples de relacions i paginació. La [fitxa de la proposta](../../../wiki/fonts/code-along-ut2-2627.md) registra les decisions i la validació. El contingut dels apunts no s'ha reescrit en preparar el projecte: encara caldrà alinear-ne fragments i rutes amb aquesta proposta, que no es registra com a impartida.

La [fitxa de configuració i dades d'exemple](../../../wiki/fonts/dades-exemple-classe-ut2.md) inventaria els dos fitxers aportats el 2026-10-09 a `materials-anteriors/0613-desenvolupament-web-entorn-servidor/UT2/dades exemple classe/`: configuració H2 comentada i 21 llibres inicials. Hi consten la comparació amb el projecte anterior, la dependència H2 del POM de referència i els punts de codificació que cal tenir presents en reutilitzar els comentaris. L'apartat 4 dels apunts ja desenvolupa les 12 propietats d'aquesta aportació i el funcionament indicat pel professor: creació de l'esquema i càrrega de `data.sql` a cada arrencada.

**Ampliació parcial, 2026-10-09:** per indicació del professor, els apunts comencen amb la definició de JPA, la justificació de l'ORM i la distinció entre JPA, Hibernate, Spring Data JPA i H2. El segon apartat explica la primera passa pràctica: afegir `spring-boot-starter-data-jpa` i `h2` al POM, les dependències transitives, el scope `runtime`, la gestió de versions i la recàrrega de Maven a l'IDE. S'han contrastat els POM d'UT1 i del code along històric d'UT2. L'índex i la numeració s'han ajustat a deu apartats; el document continua sent un esborrany. Les fonts tècniques de contrast es conserven a la [fitxa del code along](../../../wiki/fonts/code-along-ut2-2526.md), fora dels apunts d'alumnat.

**Ampliació de configuració, 2026-10-09:** l'apartat 4 incorpora el bloc complet de `application.properties`, les opcions de `ddl-auto`, els commutadors de visualització del SQL i de consola, l'ordre d'inicialització, la ubicació dels recursos i un exemple literal de les dades de llibres. Distingeix les propietats presents a la font de `spring.sql.init.mode`, explicada com a opció addicional que aquí no cal declarar. Inclou comprovacions proposades de recompte i reinici. També precisa que la consola en Spring Boot 4 requereix `spring-boot-h2console`; aquesta dependència és una adaptació documentada, no una dependència del POM històric. Les explicacions s'han contrastat amb fonts oficials recollides a la fitxa de configuració, sense executar el projecte ni alterar els originals.

**Ampliació d'entitats, 2026-10-09:** l'apartat 5 desenvolupa el mapatge de `Book` i incorpora una fitxa de consulta d'anotacions sense relacions a 5.6. S'han revisat `Book`, `Course`, `Student` i `Teacher` per recollir totes les variants emprades de `@Entity`, `@Table`, `@UniqueConstraint`, `@Id`, `@GeneratedValue`, `@Column`, `@Enumerated` i `@Transient`. La fitxa distingeix les opcions del code along de les ampliacions de taules, índexs, columnes, generadors i anotacions bàsiques habituals. Es precisa `AUTO` implícit a les tres entitats d'universitat i s'ha restituït `@Column` sense paràmetres a `publishedDate` al fragment de `Book`, com al codi. Fonts oficials i inventari a la [fitxa del code along](../../../wiki/fonts/code-along-ut2-2526.md). Per indicació expressa del professor, l'apartat 8 de relacions es conserva sense modificacions; aquestes anotacions es treballaran amb els exemples posteriors. Edició de Markdown, sense canvis al projecte ni exportacions.

Abans de donar l'esborrany per revisat, cal alinear-lo amb `unitat2_2627`, que ja exposa les consultes específiques per HTTP, corregeix el SQL natiu, defineix respostes d'error i publica universitat amb DTO. Els fragments encara basats en la còpia antiga s'han d'actualitzar durant la revisió dels apunts. Quan el contingut estigui revisat, el circuit previst és Markdown → DOCX editable → PDF exportat del mateix DOCX, amb la identitat del CIFP Pau Casesnoves i la llengua `ca-ES`.
