# Materials de la UT2 — Curs 2026–2027

La font de teoria és [acces-a-dades-amb-spring.md](acces-a-dades-amb-spring.md), amb estat **Revisat** des del 2026-10-09. S'ha revisat íntegrament com a material autònom per a l'alumnat, contrastant-lo amb el code along simplificat i l'examen d'UT2 del curs 2025–2026. El dossier DOCX i el PDF encara no s'han generat.

L'esborrany es va iniciar amb el [code along `unitat_2_classe2526`](../../../wiki/fonts/code-along-ut2-2526.md). El 2026-10-09 el professor confirma que [unitat_2_ordinador_profe](../../../wiki/fonts/code-along-ut2-ordinador-profe.md) és posterior i el designa com a **font històrica canònica**; totes dues fonts es conserven a `materials-anteriors/`. La [fitxa de la UT2](../../../wiki/moduls/0613-desenvolupament-web-entorn-servidor/unitats/ut2-acces-dades.md) conté la traçabilitat amb `RA6` i els criteris d'avaluació.

**Projecte de referència confirmat per generar els materials teòrics d'UT2, 2026-10-09:** [unitat2_2627_simplificat/README.md](unitat2_2627_simplificat/README.md), centrat en entitats i repositoris, amb serveis i controladors mínims. David Pons selecciona aquesta versió com a base dels apunts `acces-a-dades-amb-spring.md`; les revisions del contingut i dels exemples s'han de contrastar amb el seu codi. Conserva mapatge JPA, consultes, paginació, dades inicials i exemples HTTP bàsics i ampliats; compila i supera 10 proves de persistència. La [fitxa de la versió simplificada](../../../wiki/fonts/code-along-ut2-2627-simplificat.md) documenta l'abast i la verificació.

**Projecte ampliat conservat:** [unitat2_2627/README.md](unitat2_2627/README.md) i la seva [fitxa de font](../../../wiki/fonts/code-along-ut2-2627.md) documenten la primera fusió amb DTO, validació i tractament REST d'errors. Es conserva íntegre per preparar UT3 i la integració final. Aquesta progressió és la concreció del professor del 2026-10-09: UT2 focalitza persistència i UT3 introdueix el disseny de serveis web. Els apunts no s'han reescrit en preparar aquestes versions i cap de les dues es registra com a impartida.

La [fitxa de configuració i dades d'exemple](../../../wiki/fonts/dades-exemple-classe-ut2.md) inventaria els dos fitxers aportats el 2026-10-09 a `materials-anteriors/0613-desenvolupament-web-entorn-servidor/UT2/dades exemple classe/`: configuració H2 comentada i 21 llibres inicials. Hi consten la comparació amb el projecte anterior, la dependència H2 del POM de referència i els punts de codificació que cal tenir presents en reutilitzar els comentaris. L'apartat 4 dels apunts ja desenvolupa les 12 propietats d'aquesta aportació i el funcionament indicat pel professor: creació de l'esquema i càrrega de `data.sql` a cada arrencada.

**Ampliació parcial, 2026-10-09:** per indicació del professor, els apunts comencen amb la definició de JPA, la justificació de l'ORM i la distinció entre JPA, Hibernate, Spring Data JPA i H2. El segon apartat explica la primera passa pràctica: afegir `spring-boot-starter-data-jpa` i `h2` al POM, les dependències transitives, el scope `runtime`, la gestió de versions i la recàrrega de Maven a l'IDE. S'han contrastat els POM d'UT1 i del code along històric d'UT2. L'índex i la numeració s'han ajustat a deu apartats; el document continua sent un esborrany. Les fonts tècniques de contrast es conserven a la [fitxa del code along](../../../wiki/fonts/code-along-ut2-2526.md), fora dels apunts d'alumnat.

**Ampliació de configuració, 2026-10-09:** l'apartat 4 incorpora el bloc complet de `application.properties`, les opcions de `ddl-auto`, els commutadors de visualització del SQL i de consola, l'ordre d'inicialització, la ubicació dels recursos i un exemple literal de les dades de llibres. Distingeix les propietats presents a la font de `spring.sql.init.mode`, explicada com a opció addicional que aquí no cal declarar. Inclou comprovacions proposades de recompte i reinici. També precisa que la consola en Spring Boot 4 requereix `spring-boot-h2console`; aquesta dependència és una adaptació documentada, no una dependència del POM històric. Les explicacions s'han contrastat amb fonts oficials recollides a la fitxa de configuració, sense executar el projecte ni alterar els originals.

**Ampliació d'entitats, 2026-10-09:** l'apartat 5 desenvolupa el mapatge de `Book` i incorpora una fitxa de consulta d'anotacions sense relacions a 5.6. S'han revisat `Book`, `Course`, `Student` i `Teacher` per recollir totes les variants emprades de `@Entity`, `@Table`, `@UniqueConstraint`, `@Id`, `@GeneratedValue`, `@Column`, `@Enumerated` i `@Transient`. La fitxa distingeix les opcions del code along de les ampliacions de taules, índexs, columnes, generadors i anotacions bàsiques habituals. Es precisa `AUTO` implícit a les tres entitats d'universitat i s'ha restituït `@Column` sense paràmetres a `publishedDate` al fragment de `Book`, com al codi. Fonts oficials i inventari a la [fitxa del code along](../../../wiki/fonts/code-along-ut2-2526.md). Per indicació expressa del professor, l'apartat 8 de relacions es conserva sense modificacions; aquestes anotacions es treballaran amb els exemples posteriors. Edició de Markdown, sense canvis al projecte ni exportacions.

**Ampliació de repositoris, 2026-10-09:** els apartats 6 i 7 ja s'han contrastat amb `unitat2_2627_simplificat`. Detallen les quatre operacions CRUD, els retorns i les absències, les variants heretades habituals, identificadors, restriccions i sincronització amb `flush`. Les consultes cobreixen les 12 signatures dels quatre repositoris, amb noms derivats, JPQL, paràmetres, SQL natiu corregit, ordenació i `Page<Book>`. Es distingeixen rutes HTTP actuals, consultes accessibles als tests i metadades que el controlador simplificat no publica. Cinc fragments CRUD i les tres consultes declarades coincideixen literalment amb el codi; les 10 proves existents han tornat a superar `mvn verify`. Fonts oficials i abast de la comprovació a la [fitxa de la versió simplificada](../../../wiki/fonts/code-along-ut2-2627-simplificat.md). L'apartat de relacions i el codi font es conserven sense canvis.

**Ampliació de JPQL, relacions i proves HTTP, 2026-10-09:** introducció breu a JPQL des de l'SQL de MySQL de primer i comparació de noms, selecció, paràmetres i unions. L'apartat 8 desenvolupa els quatre tipus de relació, propietari, navegació, `mappedBy`, claus, taula d'unió, cascades, orfes, càrrega i transaccions, amb exemples addicionals un-a-un, un-a-molts unidireccional, autoreferències i matrícula com a entitat. L'apartat 9 explica com provar el projecte amb `.http`, amb resultats esperats i reinici de les dades. S'han executat els blocs JPQL i 23 peticions HTTP, incloses les nou peticions literals dels apunts, les relacions i tres restriccions. No s'ha repetit JUnit ni modificat el codi. Abast i fonts a la fitxa de la versió simplificada.

**Criteri de redacció per a l'alumnat:** el document ha de ser autònom juntament amb el code along. RA/CA, fonts normatives, context de converses, decisions de preparació, antecedents i estructura d'aquest repositori es documenten aquí i a la wiki. Els apunts només es refereixen a classes i recursos que necessita l'alumne al seu projecte. Les comprovacions de classe es faran amb `.http`; els tests JUnit de preparació no formen part d'aquesta guia. S'han retirat les mencions internes i els DTO com a proposta de millora, i s'han alineat també `Long`, mapatges implícits, rutes i les 14 propietats. L'historial dels paràgrafs anteriors descriu les revisions prèvies, no l'estat actual dels fragments.

**Revisió de coherència i idoneïtat completada, 2026-10-09:** contingut adequat al focus d'UT2 i coherent amb les entitats, els quatre repositoris, els serveis, les rutes, la configuració i les dades del projecte simplificat. S'han fet petits aclariments sobre constructors implícits, imports de Spring Data i reassignació amb eliminació d'orfes, i s'ha corregit una referència al nombre de peces de persistència. El contrast amb l'examen històric s'ha fet llegint `materials-anteriors/0613-desenvolupament-web-entorn-servidor/Examens2526/Examen unitat 2.docx`. Els suggeriments s'han comunicat només a la resposta al professor. Revisió documental i comprovacions estàtiques; no s'han tornat a executar JUnit ni les peticions HTTP. Les execucions dels paràgrafs anteriors corresponen a revisions prèvies.

DTO i disseny elaborat de l'API es reserven per als materials d'UT3. El circuit d'exportació previst és Markdown → DOCX editable → PDF exportat del mateix DOCX, amb la identitat del CIFP Pau Casesnoves i la llengua `ca-ES`.
