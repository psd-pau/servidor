La font de teoria en elaboració és [acces-a-dades-amb-spring.md](acces-a-dades-amb-spring.md). És un **esborrany inicial**, no uns apunts revisats ni un registre del que ja s'ha impartit. El dossier DOCX i el PDF encara no s'han generat.

Les consultes específiques de llibres que només existeixen al servei no s'han de presentar com a rutes HTTP disponibles. Quan el contingut estigui revisat, el circuit previst és Markdown → DOCX editable → PDF exportat del mateix DOCX, amb la identitat del CIFP Pau Casesnoves i la llengua `ca-ES`.
