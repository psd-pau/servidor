# Unitat X — [Títol de la unitat]

## 1. Criteris d’avaluació treballats

Aquesta unitat treballa els següents criteris d’avaluació del mòdul:

- **a)** S'han analitzat les tecnologies que permeten l'accés mitjançant
  programació a la informació disponible a magatzems de dades.
- **b)** S'han creat aplicacions que estableixin connexions amb bases de
  dades.
- **c)** S'ha recuperat informació emmagatzemada a bases de dades.
- **d)** S'ha publicat en aplicacions web la informació recuperada.
- **e)** S'han utilitzat conjunts de dades per emmagatzemar la informació.
- **f)** S'han creat aplicacions web que permetin l'actualització i la
  eliminació d'informació disponible en una base de dades.
- **g)** S'han provat i documentat les aplicacions web.

---

## 2. Objectius de la unitat

En acabar aquesta unitat, l’alumnat ha de ser capaç de:

- Entendre com una aplicació web accedeix a dades persistents
- Modelar informació mitjançant estructures adequades
- Recuperar i modificar dades emmagatzemades
- Publicar informació en un entorn web
- Documentar el funcionament de l’aplicació

---

## 3. Com ho farem (enfocament i tecnologia)

El desenvolupament de la unitat es basa en:

- Aplicació web desenvolupada amb **Spring Boot**
- Accés a dades mitjançant **JPA (Hibernate com a implementació)**
- Ús de **Spring Data JPA** per reduir codi repetitiu
- Implementació progressiva d’operacions **CRUD**
- Exemples funcionals com a base del treball pràctic

La tecnologia s’introdueix **com a eina**, no com a objectiu final.
