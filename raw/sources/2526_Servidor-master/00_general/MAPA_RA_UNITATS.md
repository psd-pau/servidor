# Relació entre unitats didàctiques i resultats d’aprenentatge

## Context de l’assignatura

Aquest mòdul introdueix l’alumnat en el desenvolupament d’aplicacions web en entorn servidor. L’assignatura combina conceptes fonamentals de l’arquitectura web amb la implementació pràctica d’aplicacions que gestionen informació, exposen serveis i interactuen amb tecnologies de client.

La progressió didàctica es basa en tres grans blocs:

- comprensió del funcionament del model web client-servidor,
- accés i gestió de dades,
- construcció d'aplicacions web i exposició de serveis.

Les unitats didàctiques integren diversos resultats d’aprenentatge quan és necessari per desenvolupar projectes complets d’aplicació web.

# Descripció de les unitats

## U1 — Introducció a la programació en entorn servidor

En aquesta unitat es presenten els conceptes fonamentals del model client-servidor, el funcionament dels servidors web i d'aplicacions, i les tecnologies associades al desenvolupament web en entorn servidor.

**Resultats d’aprenentatge treballats**

- RA1

---

## U2 — Accés a dades

Aquesta unitat introdueix les tecnologies i mecanismes necessaris per accedir a magatzems de dades des d'aplicacions web. Es treballa la connexió amb bases de dades i la implementació d'operacions de consulta i actualització d'informació.

**Resultats d’aprenentatge treballats**

- RA6

---

## U3 — Serveis web

En aquesta unitat s’introdueix el concepte de servei web i les tecnologies associades al desenvolupament i consum d’APIs. També es treballa la reutilització de serveis i fonts d’informació externes.

**Resultats d’aprenentatge treballats**

- RA7
- RA9

---

## U4 — Desenvolupament d’aplicacions web

Aquesta unitat integra els mecanismes bàsics per a la construcció d'aplicacions web completes. Inclou la generació de pàgines dinàmiques, l'ús d'estructures de control, la gestió d'estat, l'autenticació d'usuaris i la separació de la lògica de negoci i la presentació.

**Resultats d’aprenentatge treballats**

- RA2
- RA3
- RA4
- RA5
- RA8
